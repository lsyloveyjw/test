# 成长空间（微信小程序）

按参考图重构：粉色顶部、模块卡片、可爱风格；并升级为独立登录 + 绑定流程。

## 登录与绑定流程

1. 每次进入小程序从 `pages/login/login` 开始
2. 点击登录调用 `wx.getUserProfile`，直接使用微信昵称与头像
3. 若用户已绑定空间：进入成长空间首页
4. 若未绑定：进入绑定页创建空间或通过绑定码加入

## 主要功能

- 登录页（微信头像昵称直连）
- 绑定页（与登录页统一风格）
- 成长空间任务：新增/修改/删除，支持重复打卡与删除打卡次数
- 奖励页：奖励增删改
- 统计页：展示双人头像昵称、分组积分、绑定码、删除打卡次数
- 退出空间：从统计页退出并返回登录；若空间无成员，自动清除空间数据

## 页面

- `pages/login` 登录
- `pages/bind` 绑定
- `pages/home` 成长空间
- `pages/history` 奖励
- `pages/stats` 统计
