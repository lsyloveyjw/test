# 成长空间（微信小程序）

已按参考风格重构为「成长空间」，并新增独立登录页 + 绑定页流程。

## 核心流程

1. 打开小程序先进入 `pages/login/login`
2. 点击“立即登录”调用 `wx.getUserProfile` 直接获取微信昵称与头像
3. 若已绑定空间：直接进入成长空间首页
4. 若未绑定：进入 `pages/bind/bind` 选择创建空间或输入绑定码加入

## 功能

- 独立登录页（微信昵称/头像直连）
- 绑定页（创建绑定码 / 绑定码加入）
- 待打卡事件：新增、修改、删除、重复多次打卡、删除打卡次数
- 奖励管理：新增、修改、删除
- 统计面板：双人头像昵称、累计打卡/积分、删除打卡次数

## 页面

- `pages/login` 登录
- `pages/bind` 绑定
- `pages/home` 成长空间
- `pages/history` 奖励
- `pages/stats` 统计

## 使用

1. 微信开发者工具导入包含 `app.json` 的目录
2. 修改 `project.config.json` 的 `appid`
3. 在登录页授权微信信息后继续
