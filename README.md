# 我们的成长系统（微信小程序）

已按「成长打卡中心」风格重构界面：粉色顶部、圆角卡片、成长筛选、任务打卡、商城列表、成长分析对比。

## 页面说明

- `pages/home`：成长打卡中心（成长者筛选、纪念日倒计时、待打卡任务）
- `pages/history`：成长商城（货架/已下架）
- `pages/stats`：成长分析（当天/当周/当月/至今 + 对比条）

## 使用

1. 微信开发者工具导入包含 `app.json` 的目录
2. 修改 `project.config.json` 中 `appid`
3. 运行后在首页打卡并在统计页查看对比

## 常见问题

### 报错：`app.json 在项目根目录未找到`
请确认导入目录层级正确：导入目录里必须直接包含 `app.json`。
