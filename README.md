# 打卡记事微信小程序（优化版）

一个更完整的打卡记事模板，适合直接导入微信开发者工具。

## 功能

- 首页打卡：分类标签、心情选择、备注输入
- 历史记录：按分类筛选 + 删除
- 数据统计：总打卡、活跃天数、连续打卡、分类分布、最近 14 天趋势
- 全部数据使用本地存储（`wx.setStorageSync`）

## 目录

- `pages/home` 首页打卡
- `pages/history` 历史记录
- `pages/stats` 数据统计
- `utils/storage.js` 数据存储与聚合
- `utils/date.js` 日期工具

## 使用

1. 微信开发者工具导入当前目录。
2. 替换 `project.config.json` 中 `appid`。
3. 运行后即可使用。
