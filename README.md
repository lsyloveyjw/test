# 成长空间（微信小程序）

按“可爱成长打卡中心”风格重构，支持双人绑定空间、任务多次打卡、奖励管理和双人统计面板。

## 主要功能

- 微信用户注册：昵称 + 头像上传
- 成长空间绑定：创建空间生成绑定码 / 通过绑定码加入
- 待打卡事件：新增、修改、删除、重复多次打卡
- 打卡次数撤销：可删除打卡次数，且在统计中显示“删除打卡次数”
- 奖励管理：新增、修改、删除奖励项
- 双人统计：显示双方头像、昵称、累计打卡和积分

## 页面

- `pages/home` 成长空间（注册登录 + 绑定 + 任务）
- `pages/history` 奖励（奖励 CRUD）
- `pages/stats` 统计（双人成长面板 + 空间总览）

## 使用

1. 微信开发者工具导入包含 `app.json` 的目录
2. 修改 `project.config.json` 的 `appid`
3. 在首页先完成注册并创建/加入成长空间
